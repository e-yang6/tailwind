# tailwind

a valorant tool for viewing player info and auto-locking agents.

## features

- view all players in pre-game and current game
- see which side you're on (attackers/defenders) in agent select
- auto-lock any agent instantly when pre-game starts
- reveal real names of incognito/hidden players

## install

```
pip install -r requirements.txt
```

## usage

1. open valorant and log in
2. run the app:
```
python tailwind.py
```
3. click "connect"
4. use the buttons to view players or auto-lock agents

## requirements

- python 3.8+
- valorant must be running
